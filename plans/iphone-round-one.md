# iPhone 第一轮升级

已修复填空按钮提前显示答案的问题；填空时同步隐藏语法提示。学习难度、子页面、练习类型、单词和场景例句位置、隐藏答案状态以及手机面板会保存，旧存档可以直接继续使用。跟读入口改为播放操作，避免把点击次数当作完成练习。

图片缓存按解码后的像素占用计算，最多保留 24 个条目、96 MiB；这只限制缓存持有的图片，不代表整个页面的总内存上限。连续操作合并到下一帧，同一穿搭更改学习设置时不再重绘角色。穿搭册在缩略图进入可视区域附近时才渲染。断网图片显示占位，恢复联网后重新加载。

离线启动包含完整模块依赖、初始穿搭和基础语音。首次安装还会补存已经访问的素材。运行期素材缓存最多 160 个条目；首次使用、尚未下载和已被清理的服饰或语音仍需联网。已下载的音频支持 Range 请求。

页面和模块使用同一版缓存，更新通过“更新并继续”应用。现有 v8 缓存自动迁移，保留 localStorage 中的穿搭、相册和学习记录。其他应用的缓存不会删除。

## 后续发布

修改游戏代码、数据或基础素材后运行 `node scripts/build-offline-core.mjs`。脚本检查资源是否存在，并根据内容生成新的缓存版本；不要只发布部分文件。

## 验证

```text
node tests/image-cache.test.mjs
node tests/study-state.test.mjs
node scripts/check-round-one.cjs
```

使用 Node.js 22 或更高版本。浏览器脚本需要 Playwright，可用 `KOTOBA_PLAYWRIGHT` 指定其模块路径。脚本自行启动临时 HTTP 服务，以 `/kotoba-closet/` 子路径测试。

已有本地单元测试和新增回归均通过。浏览器测试使用 Edge 手机模拟，检查 375×667、390×844、430×932、844×390 四种尺寸，以及学习状态、断网启动、音频 Range、更新确认、v8 迁移、换装撤销重做、相册和导出图片一致性。没有 JavaScript 页面异常。

WebKit 未能在当前 Windows 环境启动；iPhone Safari 真机的声音、后台恢复和长期内存表现仍需实际确认。
