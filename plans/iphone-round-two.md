# iPhone 第二轮升级

本轮保留现有静态网页与 PWA 架构，不需要额外运行时依赖。

## 单品词汇

- 核对全部 115 个可选单品的缩略图，使用显式元数据维护颜色、细节和可确认的面料。
- 黑色、炭灰、黄色、金色分别教学；鼠尾草绿、蓝绿、酒红等使用更准确的词汇。
- 不再根据包包、鞋子、卫衣或发型的 ID 猜测棉、皮革、帆布等材质。
- 校准与插画不一致的中文颜色名称。牛仔衬衫使用独立的 denimshirt 学习目标，原有 T 恤进度保留；草编帽使用 かぶる。
- 优先展示描述当前单品的例句，并将通用词汇例句另行标注。已有录音继续使用，未录制的新描述通过系统日语朗读回退。

## 衣橱浏览

- 风格、颜色集中到筛选弹窗，支持与搜索、分类、收藏叠加筛选。
- 增加最近使用（最多 30 件）和当前已穿视图，显示结果数量与空状态恢复操作。
- 保存搜索、分类、筛选和最多 40 个浏览上下文的滚动位置。
- 从旧备份导入时补齐默认发型，剔除不在当前可选素材中的服饰。

## 穿搭控制

- 穿搭管理弹窗支持逐件锁定／解锁，锁定记录在存档与备份中。
- 全套随机保留锁定单品；局部随机只更换指定分类，并尽量避免重复当前单品。
- 锁定连衣裙后阻止替换上下装；锁定上下装后阻止换连衣裙。手动换装也遵守锁定。
- 已锁单品仍可点击查看日语学习卡；收起舞台后锁定提示依然可见。
- 清空只取下未锁服饰并保留发型。恢复初始和载入相册替换整套并清除锁定，可撤销恢复。

## 验证

在项目目录运行：

```powershell
node tests/wardrobe-upgrade.test.mjs
node tests/study-state.test.mjs
node tests/image-cache.test.mjs
node scripts/build-offline-core.mjs
node scripts/check-round-two.cjs
node scripts/check-round-one.cjs
```

浏览器脚本沿用本机 Playwright；其他机器通过 `KOTOBA_PLAYWRIGHT` 指定包路径。使用 Node 22 及以上。

已检查 375×667、390×844、430×932、844×390 和 1280×900 布局，以及锁定冲突、局部随机、撤销重做、筛选与滚动恢复、旧／新备份导入。第一轮离线、升级、录音 Range 和导出检查继续执行。

此环境使用 Edge 手机模拟，不能替代真实 iPhone Safari 与主屏幕 PWA 验收。
